# labops-montage

Скилл для Claude Code: Claude сам монтирует ваш рилс из сырого видео с телефона, а вы только выбираете варианты и говорите «ОК».
Автор: [labopsai](https://labopsai.pro).

## Как начать

1. Откройте Claude Code: в терминале или вашего агента в Telegram. Модель: **Opus 5.5** (команда `/model`).
   Нужна подписка Claude Pro или Max.
2. Отправьте агенту ссылку на этот репозиторий и напишите:
   **«Установи этот скилл, настрой всё нужное и веди меня по шагам»**.
3. Дальше агент сам ставит программы, говорит, где нужен ваш шаг, и ведёт монтаж.

Инструкция для агента лежит в [`SKILL.md`](SKILL.md).

## Что умеет

- Вырезает паузы, оговорки и дубли. Режет только в паузах, по реальному концу звука.
- Делает наезды на лицо: общий, средний и крупный план.
- Накладывает субтитры: 24 стиля, 8 вариантов выделения ключевых слов, караоке, появление с «пружинкой».
- Добавляет вставки (логотипы, скриншоты, мемы, цифры). Вставки ставятся рядом с головой и не закрывают лицо.
- Сам находит мемы, в том числе видео-мемы. По вашей просьбе вставляет ваши видео поверх голоса.
- Анимированная графика: счётчик цифр, столбики, окно терминала, пост, эмодзи, заголовок, список с галочками.
- Текст за головой: человек вырезается из фона и стоит перед большой надписью.
- Студийная чистка голоса через ElevenLabs (по желанию).
- Делает серые моменты: ч/б там, где вы оговорились, можно со значком загрузки.
- Добавляет эффекты: тряска, глитч (помехи, как на сломанном телевизоре), вспышка, стоп-кадр.
- Ставит звуковые эффекты, чистит голос от шума и выравнивает громкость.
- Составляет паспорт ролика и показывает все варианты на кадре вашего видео, с номерами.
- Проверяет готовый ролик: заново распознаёт речь и ищет слова, обрезанные на склейках.
- Разбирает стиль блогера по его рилсам и делает отдельный скилл «монтаж в стиле @блогера».

## Как проходит монтаж

**формат → паспорт [ОК] → выбор из каталога [ОК] → монтаж → правки [ОК] → финал**

1. **Формат.** Варианты:
   - своё видео в базовом стиле;
   - по референсу: 1–5 рилсов блогера, чей монтаж нравится;
   - с нуля: ролик из графики и голоса.
2. **Паспорт [ОК].** Агент присылает план ролика:
   - длину и темп;
   - хук на первые 2–3 секунды;
   - что вырезаем;
   - где вставки, серые моменты и звуки;
   - призыв в конце.
3. **Выбор из каталога [ОК].** Агент показывает варианты прямо на кадре вашего видео, вы называете номера:
   - субтитры;
   - выделение слов;
   - как устроен кадр во время вставки: лицо крупно, карточка рядом с головой, картинка на весь экран
     или картинка сверху, а вы снизу;
   - эффекты (их агент показывает ещё и коротким видео, чтобы было видно движение);
   - звуки;
   - серые моменты.

   Выбор сохраняется. В следующий раз хватит фразы «субтитры 3, акцент 1».
4. **Монтаж.** Сначала превью 720p. Перед отправкой агент проверяет кадры и звук.
5. **Правки [ОК].** Перед новой версией агент сверяет её с вашим списком пункт за пунктом. После вашего ОК делает финал 1080×1920.

## Что понадобится

| Что | Зачем | Обязательно? |
|---|---|---|
| FFmpeg 7.1+ | Резка, склейка, звук, финальный файл | да |
| Python 3.10+ | На нём написаны скрипты скилла | да |
| Распознавание речи | Время каждого слова: по нему режутся паузы и делаются субтитры. Варианты: ключ Groq (есть бесплатный тариф), бесплатно на своём компьютере через `faster-whisper` (медленнее) или ключ OpenAI (платно) | да, один из трёх |
| OpenCV | Находит лицо: для наездов и чтобы вставки не закрывали лицо | да (ставится вместе со скиллом) |
| MediaPipe | Бесплатная программа Google: вырезает человека из фона для текста за головой | да (ставится вместе со скиллом) |
| Node.js 22+ и HyperFrames | Анимированная графика: HyperFrames превращает анимированную веб-страницу в видео. HyperFrames скачивается сама при первом запуске | для анимированной графики |
| ElevenLabs | Студийная чистка голоса и больше звуков (в скилле 9 наших, через ElevenLabs можно сделать любые). Бесплатный тариф: 10 000 кредитов в месяц, чистка голоса около 1 000 кредитов за минуту | по желанию |
| HikerAPI | Скачивание рилсов блогера из Instagram для разбора стиля, около $0,001 за запрос. Без ключа рилсы можно прислать файлами | по желанию |
| rclone | Копирует файлы между компьютером и Google Диском: через неё агент забирает исходники и выкладывает готовые ролики | очень удобно |
| Tesseract (Mirage) | Ещё больше эффектов сверх четырёх, которые уже есть в скилле. Скачать самому: github.com/mirage-hq/Tesseract | по желанию |

Ключи кладутся в файл `~/.config/labops-montage/keys.env`, по одному на строку. Агент подскажет, как это сделать.
Свободного места на диске нужно хотя бы 20 ГБ: видео с телефона весит сотни МБ.

Установка вручную:

```bash
git clone https://github.com/DianaMarshrut/labops-montage ~/.claude/skills/labops-montage
cd ~/.claude/skills/labops-montage
pip install -r requirements.txt
python3 -m playwright install chromium
python3 scripts/doctor.py --keep
```

Самопроверка собирает тестовый ролик на 5 секунд. Если он собрался, всё работает.

## Файлы и лимиты Telegram

Если агент работает в Telegram, есть ограничение: бот **скачивает** из чата файлы до **20 МБ** и **отправляет** до **50 МБ**.
Видео с телефона весит сотни МБ, через чат оно не пройдёт.

- **Google Диск по ссылке.** Это самое простое. Залейте исходник с доступом «всем, у кого есть ссылка» и пришлите ссылку.
- **Общая папка через rclone.** Удобнее всего, если монтируете регулярно. Вы кидаете исходники в папку, агент кладёт туда готовые ролики.
- **Превью** агент присылает в 720p, чтобы влезло в 50 МБ. **Финал** в полном качестве кладёт на Google Диск.
- Видео в Telegram отправляйте **файлом**, а не как видео: так Telegram его не пережимает.
- **iCloud:** проще выгрузить видео на Google Диск и прислать ссылку.
- Правки можно присылать **голосовыми**.

## Мемы

Мемы агент подбирает сам. Скажите, где они нужны: «вставь мемы после слов „я в шоке“ и в конце». Можно и
не говорить: агент сам предложит места в паспорте ролика.

- Агент ищет мемы в Telegram-канале [@membeztexta](https://t.me/membeztexta) (мемы без надписей, в основном
  короткие видео). Вход в Telegram и ключи не нужны.
- Подбирает мем по смыслу фразы и показывает выбранные мемы в паспорте. Не понравился мем: скажите, агент заменит.
- Мем показывается 1–2 секунды: на весь экран, рядом с головой или сверху, а вы снизу. Звук мема выключен,
  ваш голос идёт дальше.
- Мемы с известными брендами и чужими логотипами агент не берёт.

## Свои видео поверх голоса

Только если вы сами попросили. Пришлите вместе с основным видео короткие кусочки (за ноутбуком, у окна…)
и скажите, где и как их показать:
- кусочек на весь экран вместо лица, голос идёт дальше;
- 2–3 кусочка одновременно, полосами одна над другой.

## Подводные камни

| Проблема | Решение |
|---|---|
| Бот не может скачать видео | Файл больше 20 МБ: пришлите ссылку на Google Диск |
| Результат не отправляется в чат | Файл больше 50 МБ: превью в чат, финал на Google Диск |
| Картинка мыльная | Telegram пережал видео: отправляйте файлом |
| Instagram не отдаёт рилс блогера | Пришлите файл или дайте ключ HikerAPI |
| Процесс оборвался посреди рендера | Кончилась память. Рендеры запускать по одному, сначала превью 720p |
| Слово обрезано на склейке | Проверка готового ролика это ловит, агент перережет с паузой побольше |
| Ошибка в слове в субтитрах | Агент поправит текст и пересоберёт субтитры. Имена и названия лучше назвать заранее |
| Вставка закрыла лицо | Агент заново находит лицо после каждой перерезки. Без OpenCV наезды идут по центру кадра |
| Агент долго молчит | Он должен писать каждые 15–20 минут. Если тишина, спросите статус |

## Правила монтажа

- Режем только в паузах, оставляем естественную паузу ~0,2 сек.
- Скорость ролика ×1,2, проходные куски ×1,3.
- Музыку не ставим: её проще добавить при публикации в Instagram. Шум убираем всегда, громкость ровная.
- Субтитры на каждом ролике с говорящей головой. Они стоят в нижней трети кадра, над подписью и ником Instagram, с маленькой буквы, без опечаток.
- Вставки не закрывают лицо. Связки между блоками («дальше», «второй момент») не вырезаем.
- Логотипы только официальные, факты и цифры не придумываем.
- У блогеров повторяем приёмы, но никогда не копируем чужие кадры, музыку и текст.

## Что внутри

- `SKILL.md`: инструкция для Claude, все шаги и команды.
- `scripts/`: скрипты монтажа. У каждого есть `--help`.
- `assets/sfx/`: наши звуковые эффекты (скрипт синтеза: `scripts/sounds_make.py`).
- Шрифты субтитров подключаются из Google Fonts (лицензия SIL OFL).
