# labops-montage

Скилл для Claude Code: монтаж вертикальных рилсов из сырого видео с телефона. Автор: [LabOps.ai](https://labopsai.pro).

Что делает:
- вырезает паузы, оговорки и дубли (склейки только в паузах, по звуковой волне);
- делает наезды на лицо (общий, средний и крупный план);
- накладывает субтитры: 24 стиля, акценты на ключевых словах, караоке;
- добавляет вставки: логотипы, скриншоты, мемы, цифры, карточку рядом с головой;
- делает серые моменты (ч/б, ч/б со значком загрузки);
- ставит звуковые эффекты, чистит голос от шума и выравнивает громкость;
- составляет паспорт ролика и показывает каталоги на кадре вашего видео: вы выбираете номера;
- проверяет готовый ролик: заново распознаёт речь и ищет слова, обрезанные на склейках;
- разбирает стиль блогера по его рилсам и упаковывает его в отдельный скилл «монтаж в стиле @блогера».

## Установка

```bash
git clone https://github.com/DianaMarshrut/labops-montage ~/.claude/skills/labops-montage
cd ~/.claude/skills/labops-montage
pip install -r requirements.txt
python3 -m playwright install chromium
python3 scripts/selftest.py
```

Нужны FFmpeg 7.1+ и Python 3.10+. Дальше скажите Claude: «смонтируй рилс», и он проведёт вас по шагам (см. `SKILL.md`).

## Ключи (по желанию)

Ключи кладутся в файл `~/.config/labops-montage/keys.env`, по одному на строку:

- `GROQ_API_KEY`: распознавание речи, есть бесплатный тариф. Без ключа можно поставить `faster-whisper`, тогда речь распознаётся бесплатно на вашем компьютере.
- `HIKERAPI_KEY`: скачивание рилсов из Instagram для разбора стиля.
- `ELEVENLABS_API_KEY`: дополнительные звуковые эффекты. На бесплатном тарифе ElevenLabs даёт кредиты каждый месяц.

## Что внутри

- `scripts/`: все шаги монтажа. У каждого скрипта есть `--help`.
- `assets/sfx/`: наши звуковые эффекты (синтез, `scripts/sfx_synth.py`).
- Шрифты субтитров подключаются из Google Fonts (лицензия SIL OFL).
